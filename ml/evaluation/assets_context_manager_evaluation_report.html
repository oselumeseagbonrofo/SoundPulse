Interpretation

Correctly Removed = the system suppressed a sound that should not have alerted in that mode.

Incorrectly Removed = the system suppressed a sound that should have alerted, creating a missed alert.

Incorrectly Removed (Urgent) = a missed urgent alert that was suppressed.

Incorrectly Removed (Non-Urgent) = a missed non-urgent alert that was suppressed.

Urgent Removed = all suppressed urgent sounds, regardless of whether the suppression was correct or incorrect.

Non-Urgent Removed = all suppressed non-urgent sounds, regardless of whether the suppression was correct or incorrect.
